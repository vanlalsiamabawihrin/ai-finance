# Australian Mortgage Broker Website

A modern, professional, and high-converting website for a mortgage broking business in Australia. Built with React, Vite, and Tailwind CSS.

## Features

- ✅ **Modern Design**: Clean, professional design with premium feel
- ✅ **Fully Responsive**: Mobile-first design that works on all devices
- ✅ **High Conversion**: Strategic CTAs and lead capture forms throughout
- ✅ **Trust Elements**: Credibility indicators, testimonials, and social proof
- ✅ **Interactive Calculators**: Mortgage repayment calculator with live updates
- ✅ **Complete Sections**: 16 comprehensive sections covering all aspects

## Website Sections

1. **Trust Bar** - Credibility statements and credentials
2. **Header Navigation** - Sticky header with logo and CTA
3. **Hero Section** - Strong headline with quick enquiry form
4. **Lender Strip** - Partner logos showcasing 40+ lenders
5. **Why Choose Us** - 4 key benefits with icons
6. **Services** - 6 loan service categories
7. **How It Works** - 4-step process visualization
8. **Loan Types** - Borrower categories (First Home, Families, Self-Employed, Professionals)
9. **Mortgage Calculators** - Interactive repayment calculator
10. **Testimonials** - 6 client reviews with star ratings
11. **About Section** - Broker profile with stats
12. **FAQ** - 8 common questions with accordion
13. **Lead Magnet** - Free guide download form
14. **CTA Banner** - Strong call-to-action section
15. **Contact Form** - Full enquiry form with contact details
16. **Footer** - Links, compliance info, and social media

## Tech Stack

- **React 18** - Modern React with hooks
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library

## Color Palette

- **Primary**: Deep Navy Blue (#0F172A)
- **Accent**: Electric Teal (#06B6D4)
- **Neutral**: Light Grays (#F8FAFC - #E2E8F0)

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Development

The project is organized with reusable components in `/src/components/`:

- Each section is a separate component
- Consistent styling using Tailwind utility classes
- Custom button and card styles defined in `index.css`
- Smooth scrolling and hover effects throughout

## Customization

### Update Business Information

Edit the following files to customize:

- **Logo & Brand**: `Header.jsx` and `Footer.jsx`
- **Contact Details**: `ContactForm.jsx`, `Footer.jsx`, `Header.jsx`
- **Testimonials**: `Testimonials.jsx`
- **Services**: `Services.jsx`
- **About Content**: `About.jsx`

### Styling

- Main styles: `src/index.css`
- Tailwind config: `tailwind.config.js`
- Custom colors and shadows defined in Tailwind config
